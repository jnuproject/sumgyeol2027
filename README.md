# 숨결 · 캠퍼스 산책

제주대학교 아라캠퍼스를 캐릭터로 걸어 다니는 Three.js 싱글플레이 웹 게임입니다. 공개 버전은 `lanes-r26`입니다.

**게임 주소: https://jnuproject.github.io/sumgyeol2027/**

앱 설치·로그인·API 키가 필요 없습니다. 지도·고도·재질·Three.js·글꼴을 함께 제공하며, 게임에 필요한 외부 API 호출은 없습니다.

## 조작

- WASD / 방향키: 이동, Shift: 달리기, Space: 점프
- 화면 드래그: 시점 회전, 휠: 확대·축소
- V: 1·3인칭 전환, R: 정문으로 돌아가기
- 정문·도서관 오르막·학생회관(신관): 중점 구역 둘러보기
- 도서관 오르막: 경상대 앞 또는 중앙도서관 앞에서 걷기 시작
- 모바일: 이동 조이스틱과 점프·달리기 버튼
- 사진 모드: 화면 도구의 카메라 버튼

산책 기록은 해당 브라우저에만 저장됩니다.

## 로컬 실행

Python 3이 있는 환경에서 저장소 폴더로 이동해 실행합니다.

```sh
python3 run.py
```

또는 `python3 -m http.server 8000 --bind 127.0.0.1 --directory dist` 후 http://127.0.0.1:8000/ 를 엽니다. `file://` 직접 실행은 지원하지 않습니다.

## 배포

`.github/workflows/pages.yml`이 `main`의 `dist/`만 GitHub Pages에 배포합니다. 원자료와 변환 스크립트는 저장소의 `source-data/`에 보존합니다. GitHub Actions에서 수동 재배포할 수 있습니다.

## 중점 구역

학교 전체 확장 대신 정문, 경상대 앞에서 중앙도서관으로 올라가는 구간, 학생회관(신관)에 집중합니다. 기존 학교 배치와 산책 기능은 보존하고, 세 구역의 메뉴·출발점·미니맵 강조를 변경했습니다. 아직 정책 내용은 추가하지 않았습니다. `dist/focus-scope.json` 참조.

## 중점 구역 모델 구체화

`detail-r20`에서 경상대1·2호관의 서로 다른 외관, 중앙도서관 정면·차양·계단·층형 수목, 신관 타일·유리 계단실·낮은 마당과 진입 계단, 정문 문주와 경비실 주변을 구체화했습니다. 경상대–도서관의 OSM 계단 선형에 실제로 걸을 수 있는 계단과 난간을 연결했습니다. 계단 단수와 치수는 측량값이 아닙니다. `dist/focus-detail-sources.json`과 `source-data/appearance/focus-detail-r20/`에 관찰과 추정을 구분했습니다.

## 이동 가능 범위

`walk-r21`에서는 정문, 경상대에서 중앙도서관으로 올라가는 구간, 학생회관 신관 및 이들을 잇는 길에서만 걸을 수 있습니다. 화면의 파란 경계와 미니맵의 강조 영역이 산책 범위입니다. 달리기·점프·대각선 이동에도 같은 경계를 적용하고, 외부 건물로 바로 이동하던 URL은 차단합니다. `scene-r22`부터 다른 건물·운동장 모델은 생성하지 않고, 세 구역과 연결 길만 표시합니다. 지도 원자료는 삭제하거나 변경하지 않습니다.

## 세 구역만 보이는 장면

`scene-r22`는 정문과 경상대1·2호관, 중앙도서관, 학생회관 신관만 모델링해 표시합니다. 도로·지형·수목·주차 차량도 선택 구역과 연결 길의 주변부로 제한하고, 바깥은 하늘색으로 가립니다. 추가 공개 사진에서 확인한 신관 상층 돌출부·원형 기둥·계단, 도서관 외벽·끝탑·표지석, 정문 보행로 가로 구조물을 반영했습니다. 출처와 추정 범위는 `source-data/appearance/focus-scene-r22/README.md` 참조.

## 가까운 주변 환경

`periphery-r23`는 세 구역과 연결 길의 보행 범위를 유지하면서 가까운 박물관·구본관·법학전문대학원·디지털도서관만 배경으로 복원합니다. 교내 도로의 왕복2차로 폭, 도서관 앞 정류장·숲길 보도, 현무암 경계와 신관 북쪽 연못/공원 난간을 사진과 OSM에 맞춰 보강했습니다. 치수·정확한 소품 위치·앞마당/연못 고도와 미관찰 면은 추정입니다. 완전한 실사/측량 재현은 아닙니다. `source-data/appearance/periphery-r23/` 참조.

## 현재 정문 기준 재검토

2026년3월 촬영 로드뷰를 다시 관찰해 돌하르방과 예전 사진에서 추정한 기와형 지붕을 제거했습니다. 현재 관찰된 낮은 연결 보는 유지합니다. 과거 사진은 이번 형태 수정에서 제외했습니다. 신관 데크·짧은 진입 계단과 마당, 창 분할·절차적 재질·게임 장면의 지역 반사를 보정했습니다. 상세 관찰/추정/철회 내역은 `dist/identity-sources.json` 및 `source-data/appearance/identity-r24/` 참조. 기존 학교 산책 기능과세 구역 제한을 유지합니다.

## 2026년 3월 주변 환경 재검토

`surroundings-r25`는 촬영월이 확인된 로드뷰로 가로수 수관과 숲 하층, 경상대 앞 연속 관목·덩굴·작은 나무, 신관 앞 가지가 드러난 수목, 작은 인터로킹 보도블록과 입체 연석을 보강했습니다. 정문 경비실의 밝은 외벽·유리·평지붕 차양을 보정했고, 도서관 관목을 각 위치에 원반 네 개를 쌓았던 오독을 수정했습니다. 보도와 아스팔트는 별도 높이로 분리하며, 교차로·정문 연장부의 표면 및 보행 높이를 회귀 검사합니다. 신관 진입로는 가로수 생성에서 제외합니다. 2026년 10월 현장 실측 결과가 아니며 개별 식재 위치·치수는 추정입니다. 사진은 게임에 포함하지 않았습니다. `source-data/appearance/surroundings-r25/` 참조.

## 간선도로 왕복 4차선 정정

사용자의 최종 현장 확인에 따라 정문부터 위쪽 간선도로는 방향별 2차선, 합계 4차선으로 수정했습니다. 위쪽을 왕복 2차선으로 줄였던 해석은 철회합니다. 차도 폭 14.4m와 소품 치수는 추정이며, OSM 중심선·굴곡 및 원천 고도는 유지합니다. 중앙선 양쪽 점선, 차로별 화살표, 정문 연장부와 보도·시설·출발점을 같은 도로 폭에 맞췄습니다. `dist/road-correction.json` 참조.

## 항공 지도 대조 r27
카카오맵 최근사진 스카이뷰를 직접 관찰했습니다. 신관 앞 수동 거리 표시 약17m를 참고해 간선도로 폭을 추정18m로 보정하고, 별도 OSM way의 연결부가6.5m로 좁아지는 문제를 수정했습니다. 일반 보도의 연속 목재 띠를 제거하고 가로수는 보도 밖으로 옮겼습니다. 촬영일은 최근사진 UI에서 확정되지 않았으며 치수·개별 수목은 실측이 아닙니다. 원본 위성사진은 게임에 포함하지 않습니다.

## 전체 건물 복원 · campus-r28
최신 요청에 따라 원자료의 학교 전체 건물59개를 다시 표시합니다. 아래 **학교 전체** 버튼으로 전체 배치를 볼 수 있고 기존 세 구역 산책 기능은 유지합니다. 경상대1호관 태양광·옥상, 경상대2호관 지붕, 중앙도서관·신관 녹색 옥상과 구조물, 경상대 뒤 주차 공간을 카카오 스카이뷰 최근사진과 대조했습니다. 가공 지도 이미지나 타일은 게임에 포함하지 않습니다. 전체 건물을 정밀 실측한 것은 아니며 일반 외관·미기록 높이·신규 치수는 추정입니다. 상세 기록은 dist/building-sources.json 입니다.
