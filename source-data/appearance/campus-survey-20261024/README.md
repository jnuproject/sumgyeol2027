# 교내 로드뷰 관찰 보정

8개 주요 권역을 실제 카카오 로드뷰에서 확인했습니다. 촬영일·대상·관찰 내용·추정 부분은 observations.json에 있습니다. 스크린샷은 작업 검증 폴더 campus-roadview-survey-20261024에 보존했고, 게임 재질로 복제하지 않았습니다.

운동장 평탄화는 원본 고도 파일을 바꾸지 않는 런타임 국소 보정입니다. 원래 래스터의 내부 중앙값을 기준으로 쓰며, 실제 경기장 표고를 측량했다는 뜻이 아닙니다. 도로·건물·수목 좌표의 실측 정밀도도 높아진 것으로 표현하지 않습니다.

동일한 산책 게임의 관찰 구역 진입 주소 예:
http://127.0.0.1:8000/?place=953564621
http://127.0.0.1:8000/?place=286237890
http://127.0.0.1:8000/?place=953546804

걷기·점프·시점 전환은 그대로이며 R은 정문 복귀입니다. 건물 내부 진입은 지원하지 않습니다. 전체 캠퍼스 재현 완료가 아니며 자연과학·생명자원·인문 및 나머지 생활관/학과동의 개별 관찰이 남았습니다.
