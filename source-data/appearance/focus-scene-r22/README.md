# 세 구역 집중 장면 · scene-r22

정문, 경상대1·2호관에서 중앙도서관으로 올라가는 구역, 학생회관 신관만 보이는 산책 게임이다. 기존 지도/고도 원자료와 캐릭터·이동·점프·충돌·카메라를 보존했다. 나머지 건물은 scene-scope.js의 허용 목록에서 제외하며, 운동장·관람석·수경 공간도 생성하지 않는다. 도로와 지형은 선택 구역과 연결 길 바깥8–22m에서 가려진다. 수목과 주차 차량도 같은 범위에 제한했다. 미니맵과 메뉴 개요도도 선택 구역만 그린다.

참고 사진은 관찰용으로만 사용했다. 사진 픽셀·파노라마·제한된 원본3D 모델·원작자 코드/텍스처는 게임에 복제하지 않았다. 새 형상·표지 글자·재질 패턴은 독자 작성했다. 사진 발행일·방문일·촬영일을 구분하며2023년 사진이 현재 상태를 증명하지는 않는다.

## 추정과 검증

계단 단수/치수, 기둥 간격, 건물 높이·미관찰 면, 표지석 위치와 수목 위치는 사진을 대조한 시각적 추정이다. 실제 측량이나 완전한 디지털 트윈이라고 주장하지 않는다. 원본 OSM 윤곽과 AWS 고도 파일은 변경하지 않았다.

자동 검증은 선택 건물 목록·영역 밖 기하 제거·원자료 불변성·연결 보행·계단 높이·주차 차량의 범위 안 배치를 포함한다. 실제 브라우저에서는 WebGL2 렌더링, 신관 계단 접근, 점프/착지와1·3인칭 전환, 각 구역 장면을 확인한다. 구체적인 적용 파일·배포 커밋·브라우저 증거는 로컬 focus-scene-r22 검토 폴더에 저장한다.
