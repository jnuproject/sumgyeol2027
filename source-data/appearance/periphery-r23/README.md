# 세 구역의 가까운 주변 환경 · periphery-r23

목표는 기존 세 구역의 산책을 유지하면서 가까운 주변도 실제 배치에 가깝게 보이게 하는 것이다. 새 비게임 뷰어나 전체 캠퍼스를 만들지 않았다. 사진/로드뷰 관찰과 추정·보정은 observations.json에 분리해 기록했다.

## 실제로 바꾼 내용

- 정문 넓은 진입 차도에서 신관 앞 왕복2차로 구간으로 좁아지는 폭을 적용했다.17.5m→7.4m와 전이 위치는 시각적 추정이다. 폭 전이점에서 원자료 선분을 표시용으로만 분할하며 도로 수평 원좌표는 그대로다. 도로 표면·보도·수목 간격과 높이 샘플러가 같은 폭을 사용한다.
- 박물관·구본관·법학전문대학원·디지털도서관만 가까운 배경으로 복원했다. 나머지 건물과 운동장은 계속 생략한다. 이동 가능 범위는 walk-r21과 같다.
- 도서관 앞 숲길 보도와 원본 geometry로 만든 정류장·벤치, 경상대 앞 불규칙 현무암 경계, 신관 북쪽 OSM 연못과 공원 난간을 추가했다. 연못 수면과 도서관 앞마당의 평탄 보정은 원 고도 자료의 중앙값을 쓴 모델링 추정이다.
- 법학전문대학원의 공개2023년 방문 사진에서 확인한 붉은 지붕, 기둥4개, 박공과 아치창을 독자 geometry에 반영했다. 미관찰 뒷면은 추정이다.
- 가로수의 과도하게 굵은 줄기와 반복 Y자 가지를 줄이고 주가지3개·세부가지6개로 나눴다. 수목 개별 위치/수종/높이/잎 무성한 계절은 재구성이다.3월 로드뷰의 낙엽 상태를 그대로 복제한 것이 아니다.
- 표시 여유를 넓히되 먼 캠퍼스는 보이지 않도록 하늘색으로 가린다. 주변부35m 이후75m까지 표시용 페이드이며 실재 안개를 측정한 것이 아니다.

## 사용 자료

직접 관찰했던 카카오 로드뷰2026-03 캡처, [정문 보도 사진](https://www.jnuri.net/news/article.html?no=67142), [2023-12-04 캠퍼스 방문 사진](https://mostadmired.tistory.com/238)을 다시 대조했다. 사진/파노라마/제한된3D 원본·텍스처를 게임 자산으로 복제하지 않는다. 사진은 로컬 검토 자료로만 보관한다. 원자료 OSM과 고도 파일은 변경하지 않았다.

## 검증과 남은 한계

도로 폭의 연속 전이, 원좌표 불변성, 렌더링 범위와 보행 경계 분리, 연못/앞마당 평탄면, 소품의 유한 좌표와 출발점 여유, 기존 보행·계단·충돌 검증을 수행한다. 브라우저에서는 새 장면의 보행·점프·착지·카메라와 도서관 오르막을 실제로 확인한다.

아직 전체 주변의 실사급 재현이라고 주장할 수 없다. 실제 치수·수목 배치·미관찰 건물 면·계단 단수·정류장/난간의 정밀 위치·고도는 추가 확인이 필요하다. 별도 실측 또는 사진측량으로 대체한 자료가 아니다.
