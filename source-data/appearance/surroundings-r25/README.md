# 주변 환경 관찰·반영 기록 — r25

이 변경은 기존 산책 게임의 세 구역(정문, 경상대–중앙도서관, 학생회관 신관) 주변 환경을 보정한다. 근거는 화면에 **2026년 3월 촬영**이 표시된 카카오 로드뷰다. 2026년 10월 25일은 자료 검토일이며, 현장 조사일이나 사진 촬영일이 아니다. 3월 자료로 10월의 실제 상태까지 확인했다고 주장하지 않는다.

공개 링크는 장소/검색 진입점이며 고정 파노라마 프레임 URL이 아니다. 촬영월을 확인한 프레임은 작업 공간의 `focus-detail-r20/references` 및 `identity-r24/references`에 검토용으로 보관한다. **이 문서와 배포 폴더에는 원본 사진·파노라마 픽셀을 넣지 않았다.** 사진을 게임 텍스처로 사용하지 않았다.

## 이번 반영

- 정문 식재를 반복 직육면체에서 서로 겹치는 둥근 관목 형태로 바꿨다. OSM 숲 범위 안에 하부 식생을 더하고, 나무의 가지와 여러 겹 잎으로 숲 가장자리의 밀도를 표현한다. 도로·건물·동선의 여유 공간은 유지한다.
- 경상대 1호관의 낮은 돌 경계에 덩굴과 연속 관목, 작은 수목을 겹쳐 표현하고 관찰된 원형 표지를 독자 형상으로 만들었다. 작은 수목 5개와 표지 위치는 추정 배치다.
- 도서관 관목의 잘못된 원반 형태를 수정했다. 기존 6개 배치 위치와 충돌 반경은 유지하며, 계단 깊이에 따라 높아지는 두꺼운 둥근 직사각형 수형과 작은 잎을 표현한다. 계단·난간·높이 샘플러는 그대로다.
- 학생회관 앞은 3월에 보이는 큰 낙엽수의 가지 구조를 반영했다. 2개 위치·높이와 공원 내 침엽수 무리는 추정이며 실제 개체 조사 결과가 아니다. 기존 마당·데크·계단은 유지하고 확인되지 않은 가구나 장식을 추가하지 않았다.
- 독자적으로 그린 맞물림 보도블록 패턴, 기존 석재 재질의 색 보정, 지면을 따라가는 입체 연석을 적용한다. 연석 18 cm 높이·25 cm 폭과 블록 크기는 모델링 값이다.

## 도서관 관목 해석 정정

이전 r24 기록의 **“각 위치마다 원반 4개를 수직으로 쌓은 수형”은 잘못된 해석으로 철회한다.** 2026년 3월 정면 자료에서 확인되는 것은 계단 깊이 방향으로 높아지는 두꺼운 관목 덩어리다. 원경의 겹침만 보고 실제 식재의 층수나 개수를 확정할 수 없다.

구현은 기존 6개 x/z 위치·1.7 m 충돌 반경을 보존한다. 이는 실제 관목 6개를 실측했다는 뜻이 아니다. 수관 높이 1.15–1.30 m, 폭 약 3.54–3.90 m, 깊이 3.30 m, 아래 받침 높이 0.58–1.68 m는 시각 추정이다. 이전 관찰 문서는 감사 이력으로 남기고, 수형 해석에는 이 정정 기록을 우선한다.

## 데이터·범위·제한

기존 OSM 수평 좌표, AWS 지형, 건물, 세 구역 이동 범위, 캐릭터·달리기·점프·1/3인칭 카메라·충돌·UI를 유지한다. 저해상도 원천 지형이 계단이나 연석의 실측 고도를 제공하는 것은 아니다. 개별 식재 위치, 종, 밀도, 치수, 숨은 면과 높이 차이는 여전히 재구성이다. 학생회관 앞 맨가지는 **3월 참고 시점**의 모습이며 10월에 잎이 없다는 주장이 아니다.

2023/2024 사진, 촬영일을 확인할 수 없는 2026 게시물은 새 외형 근거에서 제외했다. 경상대 2호관 등 남겨 둔 이전 모델을 이번에 최신 자료로 재검증했다고 주장하지 않는다. Sketchfab 지정 모델은 NoAI 제한을 확인했으므로 이번 작업의 시각 입력·메시·텍스처로 사용하지 않았다.

새 식생·보도 패턴은 독자 생성이며 기존 CC0 재질은 [재질 출처 기록](../../../dist/assets/materials/sources.json)을 따른다. 사진을 게임 에셋으로 공개하지 않는다. 실제 브라우저 렌더링·보행·배포 검증은 별도 실행 기록으로 확인해야 하며 이 자료 기록만으로 완료를 주장하지 않는다.

세부 관찰과 구현·추정 구분은 [observations.json](observations.json)에, 동일한 공개 출처 기록은 [dist/surroundings-sources.json](../../../dist/surroundings-sources.json)에 있다.
