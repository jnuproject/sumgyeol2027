# 숨결 산책 캐릭터

Kenney Animated Characters Protagonists의 skaterMaleA와 idle/run/jump 애니메이션을 사용합니다. 공식 출처: https://kenney.nl/assets/animated-characters-protagonists

라이선스는 CC0-1.0입니다. 원문은 dist/assets/characters/sumgyeol/KENNEY-LICENSE.txt에 보존했습니다. 원본 SVG는 이 폴더에 보존하고, 수정 SVG는 게임 에셋 폴더에 둡니다. 의상을 하늘색으로 바꾸고 독자적으로 그린 숨결 선 모티프를 추가했습니다. 원본 캐릭터 제작자는 Kenney이며 숨결의 독점 원작 캐릭터로 주장하지 않습니다.

기존 플레이어 충돌·중력·점프가 위치를 제어하고 애니메이션은 외형만 움직입니다. 모델과 애니메이션 출처·배포 파일 해시는 provenance.json에 기록했습니다. FBXLoader/NURBS는 Three.js r170 MIT, fflate는 MIT이며 저작권 고지를 보존했습니다.
