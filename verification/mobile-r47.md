# 모바일 우선 조작·자유 산책 검증

- 모바일 걷기 6→9m/s, 달리기 10→20m/s. 조이스틱 중앙 10% 데드존, 55% 밀기에서 전체 입력.
- 달리기는 탭 토글. 이동 손가락을 떼도 켜짐을 유지하고 대화·메뉴·창 이탈·화면 회전 시 정리한다.
- 가감속 변위를 해석적으로 적분해 5/10/15/30/60fps에서 같은 거리를 이동한다. 250ms 긴 프레임 상한, 0.3m 이하 공간 충돌 검사.
- 조이스틱 148px, 달리기 78px, 대화 선택지 52px. 세로·가로 모드에서 배치와 대화 얼굴 시점 확인. 지도는 휴대폰에서 키우고 전체 캠퍼스를 담는다.
- 이전 투어 구역 경계와 경고·파란 선 제거. 실제 지도 전체 범위 안에서 자유롭게 걸으며 건물·나무 충돌은 유지한다.
- 모바일 표면 텍스처 12장 9,804,983바이트 → 색상 4장 3,418,030바이트. 나뭇가지 단면 8→5, 나무·잎·충돌 위치 유지. 가장 가까운 일반 학생 애니메이션 6명을 우선 갱신하고 나머지는 분산한다. 느린 화면의 해상도 부담은 2초마다 확인한다.

브라우저에 실제 390×844 및 844×390 프레임을 만들어 Pointer Events로 조작했다. 물리적 휴대폰 하드웨어 FPS 측정은 아니다.

조이스틱 2초 누르기: z=-205 → -187.32 (약17.7m). 달리기 버튼을 누른 뒤 같은 조작: z=-187.00 → -147.44 (약39.6m), 버튼을 계속 누르지 않고 runHeld=true 유지. 옆으로 이동해 x=-85.2 → -45.84로 이전 제한 구역을 벗어남. blockedMoves=0, restricted=false, boundaryVisible=false.

세로 대화 선택지와 가로 2열 선택지 확인. NPC 표시는 임의 개인 이름을 정책 카테고리로 교체. 기존 대화 저장 식별자 유지. 확장된 NPC 기록은 encounters-r48.md 참조.
