# r43 — 부스 직원 대화, 앉은 자세, 중복 정책, 도서관 에스컬레이터

2026-10-27 / 로컬 `dist/` 수정. GitHub 전송·배포는 수행하지 않음.

- 학생회관 부스 중심 `[-107.8,-21]`: 보도가 아닌 건물 앞마당. 카운터 뒤의 기존 운영 캐릭터 `[-108.6,-21]`를 실제 대화 NPC로 승격하고 종전 별도 캐릭터를 제거. 앞쪽 `[-105.75,-21]`에서 대화 가능.
- 대화 NPC 4명, 각각 제주대 4·3 평화길 / 숨플페 / JNU상생협의회 / 학내 에스컬레이터 설치 한 정책씩 담당. 동일 정책을 다시 배정하던 6개 만남 제거. 일반 학생·쉼터·배너는 유지.
- 벤치: 실제 FBX 다리 길이와 관절 방향에 맞춘 자세. 엉덩이 높이 = 좌석 + 캐릭터 비율 보정, 무릎은 앞으로, 정강이는 아래, 발은 바닥 가까이. 기존 루트를 땅속으로 내리던 오프셋 제거.
- 중앙도서관 오르막: 차양이 있는 상·하행 2개 + 폭 2.22m 일반 계단. 아래 `[-107.425,120.366]`, 위 `[-107.927,200.079]`. 1.6m 양단 승강장까지 차도 밖. 원본 OSM 종점은 수정하지 않고 시설 표시만 도로에서 물림.
- 발판 애니메이션과 플레이어 운송 연결. 대화 중 운송 정지. 정책 NPC `[-111,116.8]`, 진입 마당 보강. 사용자 첨부 정책 이미지의 가상 미리보기이며 설치 확정·예산·일정 추가 없음.
