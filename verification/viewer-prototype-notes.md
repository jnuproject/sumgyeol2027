# 숨결 · 아라캠퍼스 3D

첫 화면에서 META jeju의 **제주대학교 전체 3d map**을 Sketchfab 공식 뷰어로 불러옵니다. 숨결 로고·색상·글꼴을 적용한 별도 로컬 프로젝트입니다.

## 실행

Finder에서 `실행.command`를 더블클릭하거나, 이 폴더에서 `python3 run.py`를 실행하세요. 기본 주소는 http://127.0.0.1:8000/ 입니다. 별도 앱·npm 설치나 API 키는 필요하지 않습니다. **새 3D 모델 화면은 인터넷 연결이 필요합니다.**

## 새 3D 화면

- 드래그로 회전, 휠·두 손가락으로 확대합니다.
- 아래 구역 목록 또는 모델 속 숫자로 장소를 이동합니다.
- `1인칭 탐색`을 선택하고 화면을 클릭한 뒤 WASD/방향키로 이동합니다. 드래그로 시선을, 휠로 이동 속도를 조절합니다.
- 1인칭에는 중력·충돌 처리가 없어 벽이나 바닥을 통과할 수 있습니다. `전체 캠퍼스`로 돌아올 수 있습니다.
- `둘러보기`와 `1인칭 탐색`을 바꿀 때 공식 뷰어를 다시 초기화합니다.
- 인터넷이나 외부 뷰어 오류가 나면 재시도·원본 링크·기존 산책 링크를 제공합니다.

## 모델 출처와 남은 제한

원본: https://sketchfab.com/3d-models/3d-map-66994283798747f0b8eca9ad0960c319

제작: META jeju. 공개일: 2023-01-04. 현재 캠퍼스와 차이가 있을 수 있습니다. 모델 페이지의 공식 Embed 기능과 Viewer API 1.12.1을 사용합니다. 모델의 다운로드·재배포 허가는 확인되지 않았으며 **원본 메시/텍스처를 내려받거나 게임 파일에 포함하지 않았습니다.** 공식 정보·제작자 표시·워터마크를 유지하고 `dnt:1`을 사용합니다. 생성 AI 학습·변환에 모델을 사용하지 않습니다.

이 단계는 실제 모델의 **뷰어 연결과 1인칭 탐색**입니다. 캐릭터·지면·충돌을 포함한 자체 Three.js 게임으로 전환하려면 원본 모델과 그 용도에 맞는 이용 허가를 별도로 확보해야 합니다.

신규 파일: `dist/index.html`, `campus-viewer.css`, `campus-viewer.js`, `model-source.json`. 이전 첫 화면은 `dist/walk.html`로 보존했습니다. 기존 게임은 http://127.0.0.1:8000/walk.html 에서 실행할 수 있고, OSM·Three.js·기존 게임 코드는 그대로입니다. 아래 내용은 기존 산책 버전의 문서입니다.

# 숨결 · 캠퍼스 산책

제주대학교 아라캠퍼스를 자유롭게 걷는 Three.js 싱글플레이 웹 게임입니다. 별도 앱이나 npm 패키지 설치 없이 실행합니다. Three.js도 프로젝트에 들어 있습니다.

## 가장 쉽게 실행하기

Finder에서 **`실행.command`를 더블클릭**하세요. 이 Mac에 설치된 Python 3으로 로컬 서버를 열고 브라우저를 자동으로 띄웁니다. 기본 주소는 http://127.0.0.1:8000 이며, 포트가 사용 중이면 8010까지 빈 포트를 찾습니다. 종료하려면 열린 터미널에서 `Control+C`를 누릅니다.

터미널에서도 실행할 수 있습니다.

```sh
cd /Users/goyehun/Documents/JejuCampusGame
python3 run.py
```

자동으로 브라우저를 열지 않으려면 `python3 run.py --no-browser`를 사용하세요. 수동 서버 실행은 다음과 같습니다.

```sh
python3 -m http.server 8000 --bind 127.0.0.1 --directory dist
```

`dist/index.html`을 `file://`로 직접 열면 모듈과 지도 데이터 로딩이 차단될 수 있습니다. 반드시 위 로컬 웹 주소를 사용하세요. 서버는 이 Mac의 루프백 주소에서만 실행됩니다.

## 즐기는 방법

- **산책 시작하기**: 정문에서 자유롭게 걷기
- **WASD / 방향키**: 이동, **Shift**: 달리기, **Space**: 점프
- **화면 드래그**: 시점 회전, **휠 / 두 손가락**: 확대·축소
- **R**: 정문으로 돌아가기
- **정문·박물관·구본관 버튼**: 장소 둘러보기와 해당 장소에서 걷기 시작
- **카메라 버튼 / P**: 사진 모드, **사진 저장**: PNG 내려받기, **Esc**: 돌아가기
- **해 모양 버튼**: 오후 / 저녁 분위기 전환
- **화면 설정**: 그래픽 품질, 즉시 카메라 전환
- 휴대폰 화면에는 이동 조이스틱과 점프·달리기 버튼이 표시됩니다.

세 장소의 원형 표식 근처에서 산책 도장을 얻습니다. 도장은 해당 브라우저의 로컬 저장소에만 저장됩니다. 로그인, 외부 분석 도구, 서버 전송, 멀티플레이 기능은 없습니다. 로컬 저장소를 사용할 수 없으면 이번 실행 중의 기록만 유지됩니다.

## 이번 개선

첫 화면과 모바일 UI, 하늘·조명·잔디 질감, 지도상 숲의 수목 표현, 일반 건물의 창 표현, 배낭 캐릭터와 걷기 애니메이션을 새로 다듬었습니다. 부드러운 가감속, 건물 가장자리 충돌, 카메라 가림 대응, 장소별 둘러보기, 그래픽 설정, 사진 모드와 도장 저장을 추가했습니다. 정문·박물관·구본관의 기존 사진 참고 모델은 유지했습니다.

## 파일과 출처

- `dist/index.html`, `style.css`: 화면과 반응형 스타일
- `dist/game.js`: 렌더링, 카메라, 입력, UI, 도장·사진 기능
- `dist/world.js`: 캠퍼스와 캐릭터 모델, 정적 메시 묶음 렌더링
- `dist/navigation.js`: 건물 충돌과 안전한 시작 위치
- `dist/places.js`: 장소별 설명
- `dist/campus-data.json`: 원본 지도 데이터. 건물 58개, 도로·보행로 75개, 구역 27개
- `dist/provenance.json`, `visual-references.json`: 원래의 지도·사진 출처
- `dist/presentation-notes.json`: 이번에 추가한 시각적 표현과 한계
- `dist/three.module.js`, `THREE-LICENSE.txt`: 동봉된 Three.js 라이브러리와 라이선스
- `source-data/`: OSM 원자료, 변환·검증 스크립트, 원래의 좌표 검증 결과
- `verification/`: 충돌 테스트와 이번 검증 기록

지도 데이터는 © OpenStreetMap contributors, ODbL 1.0입니다. Three.js는 MIT 라이선스입니다. 참고 사진 자체는 동봉하거나 텍스처로 사용하지 않습니다. 개별 나무 위치, 일반 건물의 창, 높이·도로 폭과 재질은 시각적 추정입니다. 지면은 평면이며, 현재 캠퍼스의 완전한 복제나 대학 공식 서비스가 아닙니다.

## 현장감 개선

정문 사진의 넓은 차도·보도·가로수·중앙 시설을 기준으로 진입부를 재구성했습니다. 1인칭은 하단 버튼 또는 V로 전환합니다. 기존 3인칭 시작 방식도 유지합니다. 새 재질은 Poly Haven의 CC0 사진 기반 자료이며 외부 연결 없이 동봉된 파일을 읽습니다. 출처와 해시는 `dist/assets/materials/sources.json`에 있습니다.

건물·도로 원본 좌표는 보존했습니다. 수목·가로등·횡단보도·문주 치수와 미확인 건물 외관은 추정한 시각적 표현입니다. 실제 지형 높이와 전체 건물 외형을 측량한 디지털 트윈은 아닙니다. `dist/presentation-notes.json` 참조.
